# Privacy Policy — Section Nav for ChatGPT

Effective date: August 8, 2026

Section Nav for ChatGPT is a local browser-extension enhancement for navigating headings and saving section bookmarks on `chatgpt.com`.

## Data processed

The extension reads heading text and limited message metadata from the ChatGPT page that is currently open. This processing is necessary to build the Section Rail, determine the active answer, and resolve saved section bookmarks.

## Data stored

When a user bookmarks a section, the extension stores the conversation key, section title, heading level, section index, message identity when available, and a short hashed answer fingerprint. This information is stored in `chrome.storage.local` in the user's current browser profile.

## Data transmission

The extension does not send conversation content, bookmarks, identifiers, analytics, or telemetry to the developer or to any third-party server. It does not use remote code or private ChatGPT APIs.

## Data retention and deletion

Bookmarks remain in local extension storage until the user removes them, clears the extension's data, or uninstalls the extension.

## Third-party services

The extension operates on ChatGPT, a service provided by OpenAI. Use of ChatGPT remains subject to OpenAI's own terms and privacy policy. This extension is independent and is not affiliated with OpenAI.
