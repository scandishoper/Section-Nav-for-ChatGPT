# Firefox local installation

## Temporary development installation

1. Extract this ZIP archive to a folder.
2. Open `about:debugging#/runtime/this-firefox` in Firefox.
3. Select **Load Temporary Add-on**.
4. Choose `extension/manifest.json` from the extracted package.
5. Open or refresh `https://chatgpt.com/`.

Firefox removes temporary add-ons when the browser restarts. Normal persistent installation on standard Firefox requires a package signed by Mozilla through addons.mozilla.org.
