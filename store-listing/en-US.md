# Microsoft Edge Add-ons listing — en-US

## Extension name

Section Nav for ChatGPT

## Short description

Navigate headings in the current ChatGPT answer and save local section bookmarks.

## Description

Section Nav for ChatGPT adds a lightweight, native-looking section rail beside the current ChatGPT answer. It detects h1, h2, and h3 headings inside the answer you are reading, highlights the current section as you scroll, and lets you jump directly to any heading without replacing ChatGPT's original conversation navigation.

Save important sections with local bookmarks and return to them from a compact Bookmark Drawer. Bookmarks are isolated by conversation and remain available after a page refresh or browser restart. The extension supports ChatGPT's single-page navigation, streaming responses, lazy DOM updates, long conversations, responsive browser widths, and both light and dark themes.

Privacy is built into the design. The extension has no backend, account, analytics, telemetry, or cloud synchronization. It does not call private ChatGPT APIs and does not upload conversation content. Bookmark metadata stays in the current browser profile through local extension storage.

Section Nav for ChatGPT is an independent extension and is not affiliated with, endorsed by, or sponsored by OpenAI.
